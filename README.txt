ШЕРСТЯНОЙ НОС — FINAL MAP V4

Карта исправлена без изменения остального дизайна:
- одна живая карта OpenStreetMap, без фонового скрина и дублей маркера;
- на компьютере карту можно перетаскивать мышью;
- обычное колесо мыши всегда прокручивает страницу и не застревает на карте;
- Ctrl/Cmd + колесо меняет масштаб карты без лишних кнопок +/−;
- на телефоне карта не перехватывает вертикальный скролл страницы;
- карта грузится лениво только рядом с секцией.

Для публикации положите index.html и папку assets/ в корень GitHub Pages.
